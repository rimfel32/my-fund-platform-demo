# My Treasury & Investment Platform (demo)

A working investment data platform I built in the course *Data Infrastructure for AI* with
[Kainetics Labs](https://kaineticslabs.com/learn): payment schedules, cash vs accrual income, a 12-month
cash-flow plan, maturity alerts, a data-quality scorecard and lineage, behind accounts with roles.

**All data is synthetic** (fictional Horizon Development Fund).

Run locally: `pip install -r requirements.txt` then `streamlit run app.py`.
